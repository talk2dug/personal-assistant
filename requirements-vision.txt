# Deliberately NOT in requirements.txt or device/requirements.txt -- torch, ultralytics
# and insightface are real GPU dependencies (see detector.py's own module docstring) that
# the Telegram bot and web UI processes must never need installed just to answer a chat
# message. Install this into its own .venv-vision on the machine with the GPU (laptop1's
# RTX 3060), the same isolation kroger-mcp and simrig's own stack already get for their
# own reasons.
#
#   python -m venv .venv-vision
#   .venv-vision\Scripts\pip install -r requirements-vision.txt
#   .venv-vision\Scripts\python -m assistant.vision_main
#
# torch: install the CUDA build matching the box's driver from pytorch.org's own index
# first (e.g. `pip install torch --index-url https://download.pytorch.org/whl/cu121`)
# -- the plain PyPI wheel is CPU-only and YOLO11n/InsightFace would silently run on CPU.
